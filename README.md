# ⚓ Cruise Bingo

บิงโก 75 ลูกแบบ Disney Cruise — เล่นสดพร้อมกันหลายเครื่องผ่านมือถือ ไม่ต้องติดตั้งแอป
เปิดในเบราว์เซอร์ได้เลย

## ฟีเจอร์

- **Real-time หลายเครื่อง** — เจ้ามือ 1 เครื่อง (จอเรียกเลข) + ผู้เล่นกี่คนก็ได้ ต่อผ่าน WebSocket เซิร์ฟเวอร์เดียว
- **บิงโก 75 ลูก** — การ์ด 5×5 คอลัมน์ B-I-N-G-O มีช่อง FREE ตรงกลาง
- **หลายการ์ดต่อเครื่อง** — ผู้เล่นถือได้หลายใบ (เจ้ามือกำหนดสูงสุดต่อเครื่อง 1–12 ใบ)
- **การ์ดร้อนลอยขึ้นบน** — การ์ดที่ตรงเลขเยอะสุดจะถูกจัดเรียงขึ้นด้านบนให้อัตโนมัติ การ์ดที่บิงโกแล้วอยู่บนสุด
- **เซิร์ฟเวอร์ตรวจบิงโกเอง** — กันโกง ใครกด BINGO ก่อนและถูกจริงเป็นผู้ชนะ
- **รูปแบบการชนะหลายแบบ** — แถวใดก็ได้ (Line), สี่มุม, ตัว X, เต็มใบ (Blackout)
- **เรียกเลขเอง หรือ อัตโนมัติ** ทุก 4 วินาที
- **ต่อใหม่อัตโนมัติ** — จอดับ/รีเฟรช/เน็ตหลุด แล้วกลับมาได้การ์ดเดิม
- **จอมือถือเต็มรูปแบบ** — auto-daub, แอนิเมชันลูกบิงโก, เอฟเฟกต์ฉลองผู้ชนะ

## วิธีรัน

```bash
npm install
npm start
```

เปิด `http://<ไอพีเครื่องเซิร์ฟเวอร์>:3000` บนมือถือทุกเครื่อง (ต้องอยู่เน็ตวงเดียวกัน หรือ deploy ขึ้นออนไลน์)

กำหนดพอร์ตเองได้:

```bash
PORT=8080 npm start
```

## วิธีเล่น

1. **เจ้ามือ** เปิดหน้าแรก → กด "สร้างห้อง + เป็นเจ้ามือ" จะได้รหัสห้อง 4 ตัว
2. ตั้งรูปแบบการชนะ + จำนวนการ์ดสูงสุดต่อเครื่อง แล้วกด "เริ่มเกม"
3. **ผู้เล่น** เปิดหน้าแรกในมือถือ → ใส่ชื่อ + รหัสห้อง + จำนวนการ์ด → "เข้าเล่น"
4. เจ้ามือกด "เรียกเลขถัดไป" (หรือเปิดเรียกอัตโนมัติ) เลขที่เรียกจะ daub ให้อัตโนมัติบนการ์ดผู้เล่น
5. ใครครบตามรูปแบบ กดปุ่ม **BINGO!** — เซิร์ฟเวอร์ตรวจแล้วประกาศผู้ชนะ
6. เจ้ามือกด "รอบใหม่" เพื่อแจกการ์ดใหม่และเล่นต่อ

## โครงสร้าง

```
server.js           เซิร์ฟเวอร์ Node.js — เสิร์ฟหน้าเว็บ + WebSocket + ตรรกะเกม/ตรวจบิงโก
public/
  index.html        หน้าแรก (เลือกเป็นผู้เล่น/เจ้ามือ)
  host.html         จอเจ้ามือ — เรียกเลข, กระดานเลข, รายชื่อผู้เล่น
  player.html       จอผู้เล่น — การ์ดบิงโก + ปุ่ม BINGO
  css/style.css     ธีมมือถือ (navy/gold แนวล่องเรือ)
  js/common.js      WebSocket ต่อใหม่อัตโนมัติ + toast + confetti
  js/host.js        ตรรกะฝั่งเจ้ามือ
  js/player.js      ตรรกะฝั่งผู้เล่น (รวมการจัดเรียงการ์ดตามจำนวนที่ตรง)
```

## หมายเหตุทางเทคนิค

- สถานะเกมเก็บในหน่วยความจำของเซิร์ฟเวอร์ (in-memory) — รีสตาร์ตเซิร์ฟเวอร์แล้วห้องหาย
- ห้องที่ไม่มีคนต่ออยู่เกิน 30 นาทีจะถูกลบอัตโนมัติ
- การตัดสินบิงโกทำที่เซิร์ฟเวอร์เสมอ ฝั่งมือถือแค่จุดปุ่มให้กดเมื่อครบ
